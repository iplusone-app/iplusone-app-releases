Web Companion – Privacy Policy

Applies to the GetiPlusOne Web Companion browser extension (Chrome / Edge, Manifest V3). Last updated: September 25, 2026. See also the desktop app privacy policy.

1. In one sentence

This extension collects nothing and uploads nothing to our servers. It only sends the text you select on a web page over loopback (127.0.0.1) to the GetiPlusOne desktop app running on your own computer, for dictionary lookup, card creation and offline translation. All data stays on your device.

2. Data we process and why

DataWhenWhere it goesPurpose
Selected text (word / sentence)When you select text or click a bubble actionLocal 127.0.0.1 desktop appLookup, card creation, offline translation
Page URL / titleWhen you click "Add reading card"Local desktop app (stored with the card)Record the card's source page
Pairing tokenAfter pairingBrowser local storage (chrome.storage.local)Authenticate to the desktop app; revocable
Target languageWhen you pick it in optionsBrowser local storageTranslation output language

Not processed: browsing history, cookies, credentials, form data, keystrokes, or page content unrelated to the feature.

3. Does data leave your device?

No. The extension only talks to http://127.0.0.1:* (loopback). There is no other network request in the code. Translation is performed locally by the desktop app (llama.cpp + Qwen), fully offline.

4. Permissions and their purpose

  • storage — store the pairing token and target-language setting (local only).
  • clipboardWrite — write to the clipboard only when you click the bubble's "Copy original" action.
  • host_permissions: http://127.0.0.1/* — communicate with the desktop app (loopback only).
  • content_scripts: <all_urls> — enable "select text → bubble" on any page. We do not inject third-party scripts and do not modify page content; the bubble renders inside our own Shadow DOM.

5. Retention & deletion

  • Unpair (extension options → Unbind): the local token is deleted and revoked on the desktop side immediately.
  • Uninstall: the browser clears chrome.storage.local and all extension data.
  • Card data lives in the desktop app's local database; manage it in the app's Card Center.

6. Sharing / selling / ads / analytics

We do not share, sell, advertise, or run analytics (no Google Analytics / Sentry, etc.). No remote code: all scripts ship with the package (MV3 default CSP).

7. Children's privacy

Not intended for children under 13; we collect no personal information.

8. Changes

Updates to this policy will bump the "Last updated" date above.

9. Contact

support@getiplusone.app · Desktop app privacy policy · Requires the GetiPlusOne desktop app installed and running locally.

网页伴侣 · 隐私政策

适用于 GetiPlusOne Web Companion 浏览器扩展（Chrome / Edge，Manifest V3）。最后更新：2026 年 9 月 25 日。另见桌面端隐私政策。

1. 一句话

本扩展不收集、不上传任何数据到我们的服务器。它只把你在网页上选中的文本，通过本机回环地址 127.0.0.1交给已在你电脑上运行的 GetiPlusOne 桌面端，用于查词、制卡与离线翻译。所有数据都留在你自己的设备上。

2. 处理哪些数据、为什么

数据何时去向用途
选中文本（单词 / 句子）你划词或点击气泡按钮时本机 127.0.0.1 桌面端查词、生成卡片、离线翻译
页面 URL / 标题你点击「加入阅读卡」时本机桌面端（随卡片保存）标注卡片来源页
配对令牌完成配对后浏览器本地存储（chrome.storage.local）向桌面端证明身份，可随时解除
目标语言设置你在设置页选择时浏览器本地存储决定翻译输出语言

不处理：浏览历史、Cookie、账号密码、表单内容、键盘输入、与功能无关的页面内容。

3. 数据会离开你的设备吗

不会。扩展只访问 http://127.0.0.1:*（本机回环），不向任何外部/云端服务器发送数据；代码中不存在除回环以外的网络请求。翻译由桌面端本地模型（llama.cpp + Qwen）完成，同样离线。

4. 权限用途（逐项）

  • storage — 保存配对令牌与目标语言设置（仅本机）。
  • clipboardWrite — 仅在你点击气泡「复制原文」时写入剪贴板。
  • host_permissions: http://127.0.0.1/* — 与桌面端通信（仅回环地址）。
  • content_scripts: <all_urls> — 在任意网页支持「划词即弹气泡」。不注入第三方脚本、不修改页面内容（仅在自有 Shadow DOM 中渲染浮层）。

5. 保留与删除

  • 解除配对（扩展设置页 → 解除绑定）：立即删除本机令牌，并通知桌面端吊销该令牌。
  • 卸载扩展：浏览器清除 chrome.storage.local 与全部扩展数据。
  • 卡片数据保存在桌面端本地数据库，删除方式见桌面端「卡片中心」。

6. 共享 / 出售 / 广告 / 统计

不共享、不出售、不投放广告；无任何分析统计（无 Google Analytics / Sentry 等）；无远程代码（遵循 MV3 默认 CSP，全部脚本随包发布）。

7. 儿童隐私

不面向 13 岁以下儿童设计，且不收集任何个人信息。

8. 变更

本政策更新时同步修改文首「最后更新」日期。

9. 联系方式

support@getiplusone.app · 桌面端隐私政策 · 使用本扩展需在本机安装并运行 GetiPlusOne 桌面端。

網頁伴侶 · 隱私政策

適用於 GetiPlusOne Web Companion 瀏覽器擴充功能（Chrome / Edge，Manifest V3）。最後更新：2026 年 9 月 25 日。另見桌面端隱私政策。

1. 一句話

本擴充功能不蒐集、不上傳任何資料到我們的伺服器。它只把你在網頁上選取的文字，透過本機回環位址 127.0.0.1交給已在你電腦上執行的 GetiPlusOne 桌面端，用於查詞、製卡與離線翻譯。所有資料都留在你自己的裝置上。

2. 處理哪些資料、為什麼

資料何時去向用途
選取文字（單詞 / 句子）你劃詞或點擊氣泡按鈕時本機 127.0.0.1 桌面端查詞、產生卡片、離線翻譯
頁面 URL / 標題你點擊「加入閱讀卡」時本機桌面端（隨卡片保存）標註卡片來源頁
配對權杖完成配對後瀏覽器本機儲存（chrome.storage.local）向桌面端證明身分，可隨時解除
目標語言設定你在設定頁選擇時瀏覽器本機儲存決定翻譯輸出語言

不處理：瀏覽紀錄、Cookie、帳號密碼、表單內容、鍵盤輸入、與功能無關的頁面內容。

3. 資料會離開你的裝置嗎

不會。擴充功能只存取 http://127.0.0.1:*（本機回環），不向任何外部/雲端伺服器傳送資料；程式碼中不存在除回環以外的網路請求。翻譯由桌面端本機模型（llama.cpp + Qwen）完成，同樣離線。

4. 權限用途（逐項）

  • storage — 保存配對權杖與目標語言設定（僅本機）。
  • clipboardWrite — 僅在你點擊氣泡「複製原文」時寫入剪貼簿。

  • content_scripts: <all_urls> — 在任意網頁支援「劃詞即彈氣泡」。不注入第三方腳本、不修改頁面內容（僅在自有 Shadow DOM 中渲染浮層）。

  • 卡片資料保存在桌面端本機資料庫，刪除方式見桌面端「卡片中心」。

7. 兒童隱私
