GetiPlusOne Web Companion

Select a word or sentence on any web page and send it to your local GetiPlusOne desktop app — dictionary lookup, offline translation and one-click cards. Nothing leaves your computer.

Add to Chrome — coming soon

What it does

Select text → bubble

Select any word or sentence and a small action bubble appears, without breaking your reading.

Look up in the desktop dictionary

Open the full entry in the desktop app's native dictionary window — all your dictionaries, audio and examples.

Offline translation

Translate with the desktop app's local engine (llama.cpp + Qwen). No network, no API key.

One-click cards

Turn the word or its sentence into a word/reading card in the desktop app, grouped under From.Web.

Stays on your computer

Data only travels over loopback (127.0.0.1). The extension collects nothing and uploads nothing.

Works with the desktop app

The companion needs the GetiPlusOne desktop app installed and paired once with a 6-digit code.

Get started in 3 steps

1

Install the extension

Add GetiPlusOne Web Companion to Chrome / Edge.

2

Generate a pairing code

In the desktop app, open Settings → Browser extension and generate a 6-digit code.

3

Pair once

Paste the code on the extension's settings page. That's it — you're ready to select text.
